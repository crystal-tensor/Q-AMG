# Q-AMG 0.3：识图与部件修正

默认图片路径已从“整体网格再切片”改为 PartCrafter 联合生成独立部件，配合本地 SAM2.1 large 前景分割。用户指定部件数，结果仍需逐件核对；数量、封闭性和并集一致不能证明真实机械结构已恢复。

## 实现与检查

- QuantumBridge 为唯一量子 SDK，保留原生电路、编译、采样、噪声与序列化。默认本机 CUDA/MPS 适配，无 GPU 则原生 CPU。
- 原生 RectifiedFlowScheduler 与权重清单一致；通用 FlowMatchEulerDiscreteScheduler 的更新符号不适用。配置检查和独立常速度 ODE 回归防止再次误接。
- MPS FP16 DINOv2 特征在公开机器人/合成图上的 CPU 参照相对 L2 偏差为 1.29/0.89，未通过 1e-3 阈值。选择 FP32 后约 7.09e-6/6.41e-6，通过。原始记录为 `artifacts/vision-precision-v1/result.json`；这些时长是诊断数据。
- 两个引导分支使用相同部件 ID，独立比较合批与分开前向计算。VAE 使用有界 SDF 采样，保留原 latent、原始部件及预处理。
- 碎片检查区分成对肢体与分散碎片云：不以“最大连通件必须占 80%”错误拒绝两只手臂。只有占总体积至少 98% 的主体可清除不足 2% 的微小碎屑；每件保存清除比例，原始输出保留。真正分散的碎片云明确失败。它仍不是语义识别证明。
- 旧图片加载失败时不保留先前茶壶或椅子，避免错把旧结果当成新图生成。可隔离逐件查看、保存名称，布尔合并形成新运行，原始分件可恢复。

真实公开机器人输入的 GPU 标准设置（50 步、1024 tokens、128 表面采样）在 `artifacts/part-aware-gpu-v4/` 完成，约 353.17 秒；CPU 预览（30 步、512 tokens、种子 0）在 `artifacts/part-aware-cpu-v4/` 完成，约 240.82 秒。两者设置和并发环境不同，不能用这些数字计算加速比。逐件查看发现混合分组及约 5.1%/5.2% 交叠，因此均未通过语义分件验收；公开图库只保留参数化机械示例，未以模型运行成功冒充识别正确。CPU 种子 42 的空表面失败及较早采样器/精度错误也保留。

## 透明杯的显式辅助重建

用户给定“盖子、杯子、杯套”三个角色。原始神经输出虽有三个封闭网格，逐件检查仍混合盖子、杯体、杯套和碎片，已另存拒绝记录；没有重写原始运行来伪装成功。

“杯类结构辅助重建”只适用于近似旋转体。SAM 提示来自显式上盖/下套区域；侧轮廓拟合锥度、杯套占比和区域颜色，神经外形提供参考标尺。生成的杯体从底部连续延伸到杯口，具有内腔与封闭杯底；杯套是外部独立环形件，不能替代杯体下半部。盖子采用连通圆盘、外圈和提片形状近似。内壁、提片、密封与间隙都不能认定为照片中恢复的制造真值。

第一轮 QB 在候选界面、假设壁厚与间隙之间实际采样，检查实体交叠；第二轮实际采样展开方向，固定杯体。候选必须有观测计数和任务见证。私有杯图与调试模型保存在忽略的 `artifacts/runs/`，不公开照片；公开源码保留同一处理算法。

本机实际辅助结果已逐件查看：三件均连通，杯体内腔连续，杯套独立。盖子向上、杯套向下的两步序列通过离散交叠采样。浏览器实际执行 3→2 件布尔合并，再恢复原始 3 件。这个结果是受约束形状近似，不能算任意图片真实部件识别已解决。

辅助重建接口也已实际执行，导出的 GLB 与逐件审查模型 SHA-256 完全相同。两轮 QB 分别使用 3/2 个逻辑比特，合计 2,560 shots；网页显示峰值 3 比特和累计 shots。参考神经阶段约 358.58 秒，辅助处理约数秒，时间分项保存，不能把复用参考外形的几秒称为从零完成三维生成。

## 来源与量子边界

PartCrafter、SAM2、QB 源码和权重清单均固定版本及校验值，见 `vendor/SOURCES.json`。应用没有调用外部图片 API，也没有用图像生成工具伪造成功截图。

已安装 Ultralytics 官方 `yolo-models`、`yolo-inference` skills，来源提交 `11e45578024f8bcfdcf1ff3faf2d9e8a80e3c919`。skills 提供工具与模型选型流程，不会改变基础模型的感知能力，也不能据此声称某项识图能力全球最强。当前项目实际分割执行使用原生 Meta SAM2.1。

GPU/CPU 的图像功能复验可以与其他检查并发，不作为受控性能对比。QB 参与结构参数和方向决策，没有加速 PartCrafter 神经去噪，也未证明物理量子优势。超导真机仍需公司端点、校准与调用凭证；离线包不能替代真实硬件结果。当前小规模子问题容易经典求解，至少 1.2 倍真实加速目标仍未达成。

最终 `scripts/test.sh` 为 60 项测试通过，并通过 Ruff 与 JavaScript 语法检查；前端生产构建通过。`artifacts/hardware-bundle-qb-v2/` 保存当前 QB 源码快照，离线核对 30 个登记输入、175 个任务及 44,800 shots 上限，未向硬件提交。
