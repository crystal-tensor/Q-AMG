# 顶部示例库

`EXAMPLES / REPRODUCIBLE` 位于页头，与产品能力说明同一行。展开后有模型缩略图、名称、类别和部件数；选择示例会收起示例区并载入独立三维部件。可再次从页头展开，原有传动装配和夹持机构继续保留。

新增十例：航空发动机、飞机、豪华轮船、Tesla Model Y、iPhone 手机、Tesla Optimus 机器人、猎鹰火箭、劳力士外形参考机械手表、炼油厂、工业机械臂。

这些是 Q-AMG 编写的参数化结构概念，模型、缩略图和元数据由源码生成。**不是从照片重建，也不是品牌官方 CAD、真实内部 BOM 或实测尺寸。** 品牌链接仅是产品参考入口；没有下载品牌模型或使用官网照片。机芯、发动机内部、手机元件和设施工艺管线尤其属于简化示意。

## 复现

```bash
uv run --locked python scripts/generate_showcases.py
uv run --locked python scripts/render_gallery_thumbnails.py
uv run --locked python scripts/export_gallery.py
npm --prefix web run build
```

生成模型位于 `artifacts/examples/<slug>/`。缩略图直接对导出的 GLB 使用 CPU 深度缓冲渲染，避免手绘插图与三维内容不一致。公开页面使用同一份文件，可旋转、展开、重新装配、逐件查看和下载；保存布尔合并与修改名称需要连接本机服务。

## 几何与 QB 来源

每例保存有名称的实体、分组、布尔并集/对称差检查、实际 QB 原生 CPU 电路计数和选中候选见证。QB 选择横向、竖向和纵向的示意展开比例，部件形状由参数化代码定义；不声称量子测量生成了这些网格，也不声称实现了量子加速。

模型之间可能存在示意连接处交叠。示意爆炸仅用于查看；单独保存的平移序列只报告实际完成的离散交叠采样，不能认证连续拆解路径、工具空间、制造连接、承载能力或安全性。品牌模型的展示边界与图片推理路径分开标注，示例不会替代上传图片失败后的结果。
