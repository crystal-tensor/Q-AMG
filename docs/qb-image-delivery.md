# Q-AMG 0.2：QB 与图片生成交付

项目已更名为 **Q-AMG（Quantum-assisted Mechanical Generation）**。本版将应用运行时迁移到 QuantumBridge，并实现通用图片输入、生成式三维、候选分件、拆解、布尔合并与原分件恢复。

## 实际执行证据

| 验证 | 当前证据 |
|---|---|
| QB 原生 CPU/GPU、编译、噪声、序列化 | 应用依赖移除 Qiskit/Aer/PennyLane；子进程阻断外部 SDK 导入后执行 QB 原生链路；独立 NumPy 矩阵与 QB CPU/GPU 概率核对 |
| 两张真实图片 | `artifacts/image-neural-v2/` 使用固定真实 TripoSR 权重，椅子和茶壶均生成 7 个候选分件，合并两件后各为 6 件；对称差约为数值零 |
| MPS GPU | 两例实际运行在 Apple Metal：神经阶段首次约 8.70 秒，同进程第二例约 2.12 秒；包含分件、校验、导出与测试合并的墙钟分别约 10.68/3.12 秒，限这两个输入和本机配置 |
| CPU 图片路径 | `artifacts/image-cpu-v1/`，同一神经模型与 QB 原生 CPU，64 分辨率茶壶生成 5 个分件、校验通过；完整生成约 5.87 秒，不与不同精度的 GPU 结果直接作速度比较 |
| 浏览器真实上传 | 机器人图片通过实际上传接口生成 12 件；浏览器勾选两件后合并为 11 件，恢复为 12 件，展开值 100、重新装配值 0；证据在 `artifacts/ui-image-evidence/` |
| 错误保留 | 首轮真实模型因未展开 OmegaConf 配置引用失败，记录在 `image-neural-v1`；修复后使用新目录重跑，未用测试占位模型替代 |
| 测试 | 54 项测试通过；HTTP 单元测试里的模型 stub 明确仅验证接口，以上真实神经结果独立执行 |
| CAD 全量验收 | `artifacts/acceptance/qb-v4/` 共 300 次生成、STEP/GLB 导出与读回通过，其中 QB 自动后端 150 次、经典对照 150 次 |
| 超导真机准备 | `artifacts/hardware-bundle-qb/` 已离线生成并校验：30 个登记输入、最多 175 个任务及 44,800 shots；未提交真机 |
| 最终网页 | 前端生产构建通过；390 px 宽度无横向溢出，三维画布、分件树和下载入口均可访问 |

GPU 神经阶段的第一次包含权重校验、模型载入与上传，第二次复用模型；该时间不包括首次 1.68 GB 权重下载。实际模型名称、输入哈希、设置、库源码快照、权重哈希、QB 测量与分件见证保存在各目录。

## 验收边界

“图片到 3D”表示单视图生成式外观，可以接收不同物体类别；当前三个示例不构成任意图片都准确重建的保证。不可见的背面、内部、真实尺寸和制造连接存在不确定性。分件由几何/颜色候选与 QB 测量选择产生，名称使用“候选分件”，没有冒充恢复了真实机械 BOM。

切开后的网格为封闭实体，检查体积和并集对称差。示意爆炸仅改变展示变换；另外的拆解序列进行离散实体交叠采样，仍不构成连续路径、工具或真实连接的认证。合并保留原始运行，未重新采样时明确记录 `quantum_resampling_performed=false`。

本版迁移验证使用与历史相同的 30 个留出输入、三档规模、五个种子和强经典参照。原始记录在 `artifacts/qb-migration/heldout/`。该轮同时发生少量图片 CPU/GPU 功能测试，属于功能压力复验；保存时长和负结果，**不把它当作 SDK 速度优劣或物理量子加速的受控比较**。

历史三轮未观察到相对强经典算法的加速。当前图片切面子目标也很小且容易经典求解。公司 QPU、校准与真机任务凭证仍缺失，实际至少 1.2 倍加速及其置信区间目标未达成。

## 交付与公开页面

本机服务使用 `./scripts/demo.sh`，默认 GPU，缺少 GPU 时 CPU。模型准备脚本支持断点续传与 SHA-256 校验；权重不写进 Git，来源、版本与校验表保留。

公开页面通过 GitHub Pages 发布：可旋转、展开、复位、查看测量与下载示例。生成新图片、保存布尔合并需连接本机服务。公开示例由显式清单导出，`artifacts/runs/` 私有上传不被打包或提交。

“原型运行”“QB 模拟/验证”“真机接入”“加速达标”分别记录。当前软件功能可以使用，完整真机加速目标仍未完成。
