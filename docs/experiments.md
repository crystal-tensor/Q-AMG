# 实验报告

## 当前与历史范围

0.2 版已迁移为 QuantumBridge 原生运行时并增加真实单图 3D 与分件/合并；本版证据见 [QB 与图片交付记录](qb-image-delivery.md)。下文三轮基准、300 次旧验收和冷启动记录属于迁移前阶段，源码与数据保留原样，不能用作 QB 新测量或真实量子硬件加速证据。

## 历史阶段状态

当前可执行原型、Apple GPU/MPS 默认后端、Aer CPU 参照及参考噪声已建立；公司超导硬件尚未接入，真实量子 time-to-target 加速目标未完成。完整目标保持未完成，没有将 GPU 数值模拟称为量子硬件优势。

- `artifacts/test-results-v2.txt`：最新 48 项测试通过，新增统计边界、离线任务包、额度拦截、提交回复丢失及真机执行器契约检查；此前 39 项记录仍保留。覆盖原问题/QUBO/Ising 等价性、独立概率参照、CPU/GPU、反馈重采样、超容量分解、STEP/GLB 和后端状态机。存在一项上游 Starlette TestClient 弃用提醒，不影响测试结果。

### 修正实体连通性后的三轮完整复现

权威目录是 `artifacts/benchmarks/registered-v2/`。每轮使用相同 30 留出实例、5 种子、6 方法，共 900 条；三轮合计 2,700 条。固定经典随机求解预算为 1,792 次评估上限，达到同一质量阈值即停止。主表为 Aer CPU 理想电路模拟，不与 Metal 的不同精度结果混作同一速度实验。

| 轮次 | 编码/参数策略 | 逻辑量子比特 | 双比特门中位数 | 平均命中时间 | 相对最快观测经典参考的配对几何平均速度比（95% CI） |
|---|---|---|---:|---:|---|
| 1 | 独热、XY、深度 2 | 6 / 8 / 10 | 66 | 7.294 ms | 0.02015 [0.01721, 0.02378] |
| 2 | 等价紧凑编码、深度 2 | 3 / 4 / 5 | 12 | 4.896 ms | 0.02886 [0.02418, 0.03442] |
| 3 | 紧凑编码、深度 1、训练集角度迁移 | 3 / 4 / 5 | 6 | 4.754 ms | 0.02880 [0.02391, 0.03515] |

三轮所有方法均达到 100% 目标命中率；QAOA 每轮 150/150 几何有效。迁移轮的 0.11849 秒训练成本按 150 次请求摊销并计入主表。原问题分类枚举约 0.166–0.172 ms 命中，小问题上的经典结构非常强。

从第 1 到第 3 轮约 1.53 倍的改善是模拟实现与编码的工程改善。相对经典的速度比仍远小于 1，不能据此声称真实量子加速。按目标停止无依据调参；后续硬件接入不会自动把现有负结果改成正结果。

### 独立统计复核、失败与消融

`artifacts/analysis-v2/` 是对上述原始记录的事后独立复算，未重新运行被测求解器、调整角度或重新运行三轮实验。保存分析源码快照、输入哈希与口径。三轮各登记 900 个槽位，2700 条全部存在，无重复键；从原始分类约束和代价直接枚举核对最优参考与返回差距，结果一致。六个场景/规模分层也保存在各轮 JSON。

新版分析按登记实例 × 方法 × 种子保留全部槽位。未命中、报错或缺失的运行，分析计费为 `max(登记时限 + 摊销训练, 实际墙钟 + 摊销训练)`；这是预先时限上的失败惩罚口径，不能当作测得的命中时间或重复直到成功的期望时间。缺失/失败不会从配对速度比分母消失。当前历史数据恰无失败，所以核心速度比点估计保持不变。后续基准自动另存同口径的 `failure-inclusive.json`。

95% 时间、差距、可行率和多样性区间按实例聚类 bootstrap，4000 次，五个种子一起重采样。150/150 成功只是这批运行的观测比例；30/30 输入全部五次成功的实例比例，其 Wilson 95% 区间为约 [88.65%, 100%]，没有将相关的五个种子当成 150 个独立输入。全零差距或相同结构的 bootstrap 区间可能退化，这不是总体确定性的证明。

多样性定义为：**每个相同输入的五次重复中，最终达标且几何有效的不同结构数**，再对 30 个输入取平均。没有跨不同输入累计结构来放大结果。

| 方法/消融 | 每输入最终结构种类均值（95% CI） |
|---|---|
| 第一轮独热 XY-QAOA | 1.30 [1.10, 1.53] |
| 第二轮紧凑 QAOA | 1.27 [1.10, 1.47] |
| 第三轮角度迁移 QAOA | 1.10 [1.00, 1.20] |
| 原问题分类枚举对照 | 1.00 [1.00, 1.00] |
| 原问题 CP-SAT 对照，第三轮 | 1.10 [1.00, 1.23] |
| 模拟退火对照 | 1.50 [1.20, 1.87] |
| 同分类接口随机采样对照 | 1.40 [1.20, 1.63] |

当前数据没有显示量子方案的最终多样性优势。第三轮原始测量的原问题可行率为 94.22% [92.94%, 95.42%]；没有修复，因此修复后与原始率相同。独热约束、结构可行性与最终有效模型比例是三个不同指标。

量子第三轮平均每运行 256 shots、1 次后端调用、5.33 个双比特门；退火平均访问 53.49 个候选，分类采样平均 12.07 个候选，各方法均按达标早停。观察到的候选池、训练批次或不同角度的计数混合，不能当作同预算的分布熵比较。当前多样性消融描述的是**同一质量阈值下实际早停策略的结果**，没有声称独立证明采样分布更有表达力。

第三轮决策到几何有效的速度比为 0.9580 [0.9415, 0.9688]，相对逐实例最快观测经典参照，全部 30 个实例纳入。此口径包含实际几何生成和校验、摊销训练，不含文件导出和进程启动。逐实例挑选最快观测经典方法是偏乐观的描述性参照；JSON 同时给出对每个登记经典方法的独立配对结果。当前来源全部为模拟器。

### 独立进程启动与同进程重复

`artifacts/startup-v1/` 预先登记顺序和设置：两个五组决策的代表输入 × GPU auto/经典两模式 × 五个独立 Python 进程，每进程首次生成后再重复两次，共 20 个进程、60 次完整生成，全部通过几何与 5% 质量阈值。每次仍重新编码、编译、生成实体、检查拆解并导出 STEP/GLB/JSON。后验质量核对不提供给量子生成器。

| 输入/模式 | 新进程启动到首次文件输出均值（范围，秒） | 同进程重复完整生成均值（秒） |
|---|---:|---:|
| 传动 / MPS GPU | 7.87 [7.75, 7.99] | 4.18 |
| 传动 / 经典 CPU | 7.05 [6.89, 7.19] | 3.99 |
| 夹持 / MPS GPU | 5.79 [5.71, 5.90] | 2.11 |
| 夹持 / 经典 CPU | 4.98 [4.85, 5.08] | 1.93 |

表中范围是最小/最大观测值，不是置信区间。库导入平均约 3.0 秒。使用 [Python 3.12 系统级 monotonic 时钟](https://docs.python.org/3.12/library/time.html#time.monotonic) 对齐父进程启动与子进程首次输出时间。系统页缓存、共享库缓存和 GPU 驱动缓存保持现状，这是 **Python 进程冷启动**，不是机器重启或操作系统冷缓存测试。两个输入的结果不能推广为整个留出集的性能；与下节长进程批处理均值也不能直接混用。

启动记录在运行前保存了源码哈希；运行后补存的源码副本逐字节匹配这 19 个哈希，恢复过程单独记录于 `snapshot-recovery.json`，没有将补存副本说成运行前已经归档的快照。开发最初一次 CAD 动态库载入曾约 80 秒，只作为当时个例保留，不作为通常启动时间估计。

### 超导真机实验准备

`artifacts/hardware-bundle-v1/` 已离线生成并校验：150 次留出结构任务 + 25 次基础电路检查，上限 175 任务、44,800 shots。保存逻辑 QPY/QASM、参数、原问题、阈值、训练来源和哈希。实际门集/拓扑在获得设备能力后查询；原生电路提交前保存请求和电路哈希，收到回复立即保存提供商任务 ID。错误会停止后续提交，超时尽力取消，未知是否成功的提交不自动重试。执行方法见 [超导接入说明](company-protocol.md)。

任务包准备与预览没有访问 QPU；运行器仅通过清楚标注的 mock 契约测试。真实设备来源、校准、计费和加速仍待验证。

### 完整文件流程的墙钟

GPU 默认路径验收中，生成、几何校验、离散拆解检查及导出的平均总时间为 0.34093 秒，加入 STEP/GLB 重新读入验证后为 0.36253 秒；同次实验经典对照分别为 0.17963 秒和 0.20107 秒。这里覆盖 150 次各模式的结果，含实际导出，库导入另行记录。CPU 验收的独立数据保留在 `artifacts/acceptance/v2/`，不把不同运行批次直接当作严格 GPU/CPU 对照。

GPU 的门矩阵准备、数据传输、概率读回和主机采样都有成本；设备演化为 complex64，Aer 为 complex128。当前 GPU 后端将未单独观测的上传/读回字段标为 null，均包含在模拟器墙钟与总墙钟中。早期 GPU 验收记录的细分标签不能被解读为物理 QPU 的零上传或零读出成本。

当前主机编码、建电路与编译的中位数仍约 2.9–3.3 ms，高于此任务的最快经典命中时间。若维持这些固定开销，即使把设备演化时间假设为零，也无法得到 1.2 倍整体优势；这只是对当前路径的条件分析，不是未来所有量子算法的下界证明。

### 参考噪声表征

`artifacts/noise-characterization.json` 对单个小实例固定同一组角度，各执行 2,048 shots，不做额外调参。独热编码合法率在示意双比特误差率 0 / 1% / 3% 时分别为 100% / 77.39% / 49.80%；紧凑编码的分类映射始终合法，但这不保证轴承匹配等原始约束成立。

该例的原始约束可行率在加入噪声后可能上升：坏角度的分布被噪声展平，偶然产生更多可行点。这不能据此声称噪声普遍有益。这里没有真实校准、T1/T2、泄漏、串扰或漂移，不能作为公司设备性能预测。

### 保留的失败与修正

`artifacts/acceptance/v1/` 中 300 次完整回读有 42 次零件数不一致：两块夹垫的槽切穿了背板，每块变成两个不连通实体。旧的 isValid 检查会接受多实体 Compound，较弱的几何检查因此给出过乐观的通过率。修复槽深为 0.75 mm，补上每零件恰一个实体的门槛及 STEP 回归测试后，CPU v2 与 GPU v3 的 300 次验收分别全部通过。

初版迁移基准还存在经典随机评估预算随量子迭代数变化的记录不一致；修复为独立固定预算，保留旧记录，并完整复现三轮。历史数据不删除、不覆盖，也不作为最终加速结论。

## 首轮开发实验

原始数据：`artifacts/benchmarks/round-1-xy/raw.jsonl`；配置与依赖：同目录 `manifest.json`；数据划分：`corpus.json`；统计：`summary.json`。

30 个留出实例，传动/夹持各 15 个；三档独热变量规模 6/8/10；每例 5 个种子。每方法 150 次，总共 900 次。库已导入、每问题编译冷。没有真机，无硬件时间外推。

| 方法 | 达标率 | 平均命中时间（秒，成功运行） |
|---|---:|---:|
| QAOA XY，Aer 理想模拟 | 100% | 0.007360 |
| 原问题分类枚举 | 100% | 0.000167 |
| CP-SAT 原问题 | 100% | 0.000893 |
| CP-SAT QUBO | 100% | 0.001339 |
| 模拟退火 | 100% | 0.000852 |
| 分类采样 | 100% | 0.000328 |

QAOA 返回几何 150/150 有效。相对每实例最快观测经典参考的几何平均速度比为 0.01885，按实例配对 bootstrap 的 95% CI 为 [0.01550, 0.02284]。小于 1 表示模拟较慢。这既没有证明量子加速，也不能据此证明未来所有真机方案都无优势。

这些任务只有 3–5 个二元分类选择；强经典方法可以利用该结构，所以经典对照非常快。实测说明当前原型的主要意义是验证结构决策、编解码与几何闭环，不能将它包装成计算优势演示。

## 三轮复现登记

`scripts/reproduce.py` 在运行前写入 `registration.json`，并让各轮保存 `source_snapshot` 与 SHA-256。第一轮开发实验发生在加入源码快照功能之前，不能事后伪称已记录当时源码版本。

1. 参考：独热可行域 XY-QAOA，深度 2，最多 12 次参数更新。
2. 编码：同一原问题精确代换为紧凑二进制，逻辑比特减半，去除 XY 逻辑门；候选与约束不变。
3. 摊销：深度 1，仅训练集上按场景/规模拟合角度；留出集固定角度运行，将训练实测时间按预登记 150 次请求分摊。

每轮都保留强经典对照，不将工程表示变化与模拟器运行效率改善称作实际量子优势。运行脚本生成的所有结果必须披露，即使某轮变慢或失败。
